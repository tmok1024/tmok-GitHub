# 📈 株式リアルタイム売買シグナルアプリ

スキャルピング対応のリアルタイム株式チャート・売買シグナルシステム

## 機能

### チャート・テクニカル指標
- **ローソク足チャート** - リアルタイム更新 (WebSocket)
- **移動平均線** - SMA 20, SMA 50, EMA 9
- **ボリンジャーバンド** - 2σ バンド
- **RSI** (14期間) - 売られ過ぎ/買われ過ぎ検出
- **MACD** (12,26,9) - ゴールデン/デッドクロス検出
- **ストキャスティクス**, **ATR**, **VWAP**, **OBV**

### 売買シグナル
- 総合シグナル (買い/売り/様子見) + 強度%表示
- 色変化によるリアルタイム視覚表示
- 各指標ごとの個別シグナルカード
- シグナルメーター (売り ← 中立 → 買い)

### 時間足対応 (スキャルピング)
- 1分, 2分, 5分, 15分, 30分, 1時間, 日足
- リアルタイム更新: 1-5分足は5秒間隔

### 自動売買 (シミュレーション)
- シグナル強度ベースの自動エントリー/エグジット
- 損切り/利確ライン設定
- 取引ログ表示
- ※実際の注文機能は別途証券API接続が必要

## クイックスタート

### Docker (推奨)
```bash
cd stock-trading-app
docker-compose up --build
# http://localhost:80 でアクセス
```

### ローカル開発
```bash
cd stock-trading-app/backend
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
# http://localhost:8000 でアクセス
```
